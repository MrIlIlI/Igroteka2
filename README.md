# Игротека

Сайт с подборкой игр для детей. Открывается по адресу: https://mrilili.github.io/Igroteka2/

Структура:

- `index.html` — главная страница с каталогом игр (массив `GAMES` внутри файла)
- `games/` — игры, которые живут прямо на сайте:
  - `pesok`, `sleepy`, `svetlyachok`, `hor`, `labirint`, `plyg`, `pary`, `schet` — сделаны ИИ
  - `trex/`, `fluid/`, `maze/`, `piano/` — игры с открытым кодом; в каждой папке лежат `LICENSE.txt` и `SOURCE.txt` с источником и списком изменений
- `img/` — обложки (квадратные PNG 512×512)
- `docs/` — промпт и отчёт внешнего ресёрча, по которому добавлялись игры
