## 0. How to read this file

- Verification marks used everywhere below:
  - **[opened]** - I loaded this URL in the built-in browser on 2026-11-04 and looked at the result. It means the page or game loaded. It does not mean I played it to the end.
  - **[license-read]** - I read the raw LICENSE file myself in the browser.
  - **[file-read]** - I fetched a raw source file or a GitHub API listing myself in the browser on 2026-11-04 and searched it.
  - **[agent-read]** - text read by a helper agent through a text-only fetch (no JavaScript run, no game seen). Treat it as a lead, not as a fact.
  - **(не проверено)** / **(unverified)** - nobody checked it.
- Fields of every entry in section 3 follow the template from the brief. The field names stay in Russian so the template stays machine-readable.
- Category names map to `kind` keys in the `GAMES` array (from the `KINDS` object on the live page): Прыжки = jump, Приключения = adventure, Головоломки = puzzle, Думаем = think, Ловкость = skill, На двоих = two, Память = memory, Счёт = numbers, Рисуем = draw, Музыка = music, Спокойно = calm.
- The grid shows square covers (`aspect-ratio: 1/1`, `object-fit: cover`), so a non-square image is cropped from the center. Pad or crop every new cover to 1:1 (512x512 or larger) and save it as `img/<slug>.png`. If a cover file fails to load, the card falls back to the `emoji` tile, so a missing cover does not break the grid.
- Ages, priorities and 0-100 scores are my judgment unless a source states an age. A score answers one question: how much does this card improve the site for a child of 5-8 who may read poorly?

## 1. Summary (Краткое резюме)

1. The catalog (125 cards) is wide but thin in places: Счёт has 4 cards, Рисуем 5, Приключения 6, Память 6, Спокойно 7. By title it has no jigsaw puzzle, no alphabet game, no free paint tool and no piano.
2. I propose 17 new cards (section 3A-3C). Four of them are small enough to copy into `games/` because their code license allows it: T-Rex runner (BSD-3-Clause), fluid toy (MIT), Maze Maker (MIT) and the 1Keys piano (GPL-3.0). JS Paint (MIT) may be copied too, but a full copy is about 51 MB and its Russian strings are in doubt, so I propose a plain link to jspaint.app first. I read all five license files myself. The other 12 cards are plain links; one of them, Blockly Games «Пазл из блоков», has an optional offline bundle (Apache-2.0 per the GitHub API; I did not read the LICENSE text).
3. All 17 card pages opened in the built-in browser, but the Santa Tracker app stayed on a loading screen for 10 s. I did not play any of them to the end, and I did not test sound, ads over time or long sessions. Gaps are listed in section 6.
4. Most new cards are Russian or need no reading. Exceptions: PhET "Number Play" has no Russian build (the `_ru` file returns 404, and `locale=ru` still showed English labels); Maze Maker has English labels; Minecraft Classic has an English game menu; Blockly «Пазл из блоков» is in Russian but its first level needs reading; JS Paint follows the browser language (Russian in my browser) except for its Extras menu.
5. What a child sees around the game differs a lot. Играемся pages carry three banner slots labelled «Реклама» (no ad frame had loaded when I looked) and a comment form, no sign-in. The text of Karusel game pages contains a window about logging in or registering [agent-read], although the puzzle app page asked me for nothing. On English Poki pages an ad break is shown before the game [agent-read]. Each entry has a line for this.
6. Covers for the 17 placeholders (section 4): a documented permission exists only for a few images: a Pac-Man frame (CC BY 3.0), Quick, Draw! sample drawings (CC BY 4.0), and free Wikimedia Commons pictures that stand in for Сапёр, Змейка, Крестики-нолики, Шахматы and Мелодия. The Lichess logo may be used only to refer to lichess.org. Google's brand page lists Doodles among the things not to use, in any form. The Uchi.ru user agreement forbids using its logos and images without its direct consent, and I found no press kit. For Учи.ру the safe routes are an own neutral cover or a written request to pr@uchi.ru.
7. Order (section 5): the 17 new cards come first, Учи.ру moves from position 56 to 18, the 8 robot games move from 1-8 to 46-53, and every other card keeps its relative order except 27 hand-picked older cards that move up to 19-45.
8. Risk: 117 of 125 cards depend on third-party URLs. Wikipedia says a Nintendo complaint took Full Screen Mario, the game behind the card «Супер Марио», down [read by me through the Wikipedia API]; the card links to a page on joshuakgoldberg.com, so cards can vanish. A weekly link check (idea 9 in section 2) is the cheapest protection.
9. A blanket "play inside the site" mode would fail for many sources. In my iframe test on github.io the pages of Yandex Games, Poki, Y8, Google Doodles and Search games, Lichess Learn, Quick, Draw!, Code.org, Duolingo, ChessKid and FRVR stayed blank for 35 s while other tiles rendered. I could not read response headers, so the cause (frame blocking) is an inference. Keep opening in a new tab as the default.
10. PhET changed all simulations from CC BY to CC BY-NC on 2026-03-30 [opened: the PhET blog post of that date, read by me]. Link to PhET, do not copy it into `games/`.
11. Santa Tracker is a December collection; the page title and a cookie notice loaded in Russian, but in my browser the app stayed on a loading screen for 10 s, so I saw neither its menu nor its games. The card is placed last in the new block; open it once in a normal browser first, and move it to the top row in December.
12. My own tools had limits: text-only fetching stopped working for a while (usage limit), so some license and policy statements below are marked [agent-read] and should be re-checked by a person before they are relied on.

## 2. Site ideas (Идеи для сайта)

How the site works today (read from the live page, so the effort estimates below are based on it): one `index.html` with an inline `GAMES` array, category pills, a "Сделал робот" pill, a dice button that opens a random card inside the current filter, and a detail sheet with a single Play link. There is no favorites list, search, age filter, timer or in-page player.

Effort scale as in the brief: легко (a few lines in `index.html`), средне (new data field plus UI, or a new `games/` folder), сложно (new moving parts that need testing on real devices).

### A. Functions of the site

**1. Избранное ("Мои любимые")**
- Что это: a heart button on the detail sheet and a «Мои любимые» pill that shows only the hearted cards.
- Зачем ребёнку: children tend to go back to a few games (my assumption, I have no usage data), and the catalog will hold 142 cards. A pill with only those saves scrolling and removes the need to read names.
- Сложность: легко.
- Источник: browser `localStorage`, https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage [opened]. Keep a try/catch around every read and write, because storage can be blocked.

**2. Ряд «Недавно играл»**
- Что это: the last six cards opened, shown above the grid (or as one more pill), stored the same way as favorites.
- Зачем ребёнку: a child often wants yesterday's game again (my assumption); this needs no search and no reading.
- Сложность: легко.
- Источник: same `localStorage` page as above.

**3. Фильтр по возрасту («Мне 5 / 6 / 7 / 8»)**
- Что это: four big buttons that hide cards whose `age` is above the chosen number.
- Зачем ребёнку: the age labels in the brief run from 3+ to 8+, and 61 of the 125 cards are labelled 6+ or older (39 + 21 + 1), so a 5-year-old scrolls past many cards meant for older children.
- Сложность: легко. The `age` field already exists on every card.
- Источник: the site's own `age` field. Caveat: those ages are estimates (the sources do not state ages), so label the filter as a suggestion.

**4. Значок «Новое»**
- Что это: a new optional field `added: 'YYYY-MM-DD'`; cards added in the last 30 days get a small badge.
- Зачем ребёнку: the 17 new cards become visible as new without a separate page, and the parent does not have to maintain the order by hand.
- Сложность: легко.
- Источник: the existing `.badge` style used for «🤖 РОБОТ» in the page CSS.

**5. Подборки (collections) through a `tags` field**
- Что это: an optional array such as `tags: ['быстро']`. Pills such as «Быстрая игра», «Играем вместе», «Новый год».
- Зачем ребёнку: the current 11 categories describe the type of game, not the situation. A parent picks by situation, for example a quick game or a game to play together.
- Сложность: средне, because someone has to tag the cards by hand (start with the 20-30 cards you want in each collection).
- Источник: first candidates for «быстро»: Динозаврик-бегун, Цветные брызги, Лабиринты (all start with no menu). For «Новый год»: Деревня Санты (section 3B).

**6. Озвучка названий и описаний для тех, кто ещё не читает**
- Что это: a small speaker button on the detail sheet that reads the card name and description aloud in Russian with the browser's built-in speech synthesis.
- Зачем ребёнку: a child of 5-6 may not read the description text yet and relies on pictures.
- Сложность: легко to add, but the result depends on the computer: a Russian voice must be installed. I did not test which voices the family PC has (unverified). Hide the button when no `ru` voice is found.
- Источник: https://developer.mozilla.org/ru/docs/Web/API/SpeechSynthesisUtterance [opened].

**7. Ограничение времени игры**
- Что это: the parent picks 10, 20 or 30 minutes; at the end the catalog shows a friendly "пора отдохнуть" screen.
- Зачем ребёнку: the break comes from the site, not from an argument.
- Сложность: средне, with a limit that matters: a game opens in another tab, and the catalog cannot close a tab it holds no reference to. One route: open the game with `window.open` and keep the returned reference. MDN says a window opened with `Window.open()` may be closed by script. I did not test closing a tab that has already navigated to another site (unverified), and a popup blocker may interfere. The other route is a soft overlay shown only on the catalog tab. Decide this with the owner before building.
- Источник: https://developer.mozilla.org/en-US/docs/Web/API/Window/close [opened; I read the paragraph on windows that scripts may close].

**8. Игра внутри страницы и полный экран**
- Что это: for cards that allow it, show the game in an `<iframe>` on the site with a «Назад» button and a full-screen button.
- Зачем ребёнку: one place, no stray tabs, and a back button that is always in the same place.
- Сложность: средне. The test result decides the design: in my iframe test on github.io these rendered: CoolMathGames, Uchi.ru, Chrome Music Lab, Silk (weavesilk), Patatap, Amanita (The Quest for the Rest), Townscaper, Blockly Games, Играемся, Vectorpark, Line Rider, the hosted Full Screen Mario page and Blob Opera. These stayed blank: Yandex Games, Poki, Y8, Google Doodles (`google.com/logos`), Google Search games (`google.com/fbx`), Lichess Learn, Quick, Draw!, Code.org Studio, Duolingo, ChessKid and FRVR. The usual cause of a blank frame is the `X-Frame-Options` or CSP `frame-ancestors` header, but I could not read the headers, so that is an inference. So: add a per-card flag `embed: true`, set it only for self-hosted `games/*` cards and the cards that rendered, and keep "open in new tab" for the rest.
- Источник: https://developer.mozilla.org/en-US/docs/Web/API/Fullscreen_API/Guide [opened]; why frames go blank: https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/X-Frame-Options [opened].

**9. Проверка живых ссылок раз в неделю**
- Что это: a GitHub Action that checks every `url` in `index.html` about once a week and opens an issue listing the dead ones.
- Зачем ребёнку: a child who taps a dead card loses trust in the whole site. 117 of 125 cards live on other people's servers. Full Screen Mario shows the risk: Wikipedia says a Nintendo complaint took the game down and a second complaint later removed its source; the card «Супер Марио» links to a page on joshuakgoldberg.com [file-read, https://en.wikipedia.org/wiki/Full_Screen_Mario].
- Сложность: легко (one workflow file).
- Источник: https://github.com/lycheeverse/lychee-action [opened]. Some sites may refuse automated checks (unverified for the sites in this catalog), so expect some false alarms and keep an ignore list.

**10. Строка «Что вокруг игры» для родителя**
- Что это: a `around` field on every card ("реклама", "нужен вход", "чат", "полный экран") shown in small text on the detail sheet or on a parent page.
- Зачем ребёнку: the parent decides once, per card, whether the page around the game is acceptable. The brief asked for this information for every new card, so section 3 already contains it.
- Сложность: легко for the field, средне to fill the 125 old cards (not checked here).
- Источник: the «что вокруг игры» line of each entry in section 3.

**11. Печать лабиринтов**
- Что это: keep the Print button of Maze Maker visible in the self-hosted copy so a parent can print a maze for paper play.
- Зачем ребёнку: a break from the screen that still feels like the same game.
- Сложность: легко. Maze Maker has Download PNG/SVG and Print among its settings [opened].
- Источник: https://github.com/evoluteur/maze-maker (MIT, license file read).

## 3. New games and resources (Новые игры и ресурсы)

I am not a lawyer: this is how I read the licenses, not legal advice.

### 3F. Data table for the 17 cards (fields of the `GAMES` array)

Rules for the fields, read from the live page's code and from the `GAMES` array in the browser on 2026-11-04 [opened]:

- `age` is a number; `players` is a string (`"1"`, `"1-2"`, `"2"`, `"2-4"` occur today).
- `source` is display text only: the detail sheet prints it (robot cards print «Сделал робот · эксперимент» instead), so a new value is safe. The 125 current cards use: Яндекс Игры 33, Google 30, Poki 27, Другой сайт 15, Сделал робот 8, Y8 5, Играемся 2, FRVR 1, Tetris.com 1, Blockly Games 1, Code.org 1, ChessKid 1. The table reuses «Играемся», «Poki», «Google» and «Blockly Games» as they are and names the site for the rest. For author sites the catalog's own habit is «Другой сайт»; either is fine, but keep one spelling per site.
- `color` only tints the emoji tile that shows when the cover file is missing. `#3d2c6e` is the most common value; use it for every new card.
- `controls` is a short Russian phrase in the style «Мышка: открывать карточки» or «Стрелки: влево, вправо, вверх - прыжок, вниз - кувырок».
- `note` is optional: a short Russian remark for parents (live examples: «Меню по-английски.», «Подсказки на экране по-английски.»). Proposed notes are in the last column; "-" means no note.
- `pixel: true` is optional and switches the cover to `image-rendering: pixelated`; the current robot games use it for pixel-art covers. Consider it for «Динозаврик-бегун» if the cover is a small pixel-art screenshot.
- `desc` is the «описание» line of the entry in 3A-3C. `img` is the file to create (see the cover notes in each entry; the cover is shown square). For the four small self-hosted cards (trex, fluid, maze, piano) `url` is the path after copying; for «Рисовалка» it is the live address, and the path `games/jspaint/index.html` applies only if you decide to self-host (about 51 MB).

## 6. What I could not verify, and why (Что не удалось проверить и почему)
